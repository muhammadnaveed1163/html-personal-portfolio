```markdown
# Images

This folder contains images and visual assets used by the portfolio website.

## Recommended File Names

Use clear and professional file names:

- profile.jpg
- profile.webp
- project-01.png
- project-02.png
- project-03.png
- portfolio-screenshot.png

Avoid spaces in file names.

Example:

Good:
project-01.png

Avoid:
My Project Final Image.png
```
